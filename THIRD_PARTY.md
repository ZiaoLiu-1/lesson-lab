# Dependencies and attribution

The text demo uses Node.js built-ins and browser APIs; no npm packages, bundled fonts, stock images, university slides, model weights, or speech binaries are distributed here.

The optional local voice installer downloads whisper.cpp, CMake, and an English Whisper model from their upstream sources into ignored local storage. Their own licenses and notices apply; the project's MIT License does not replace them. The installer pins versions and verifies download hashes. See the URLs and checksums in `scripts/setup-local-voice.js` and [voice setup](docs/VOICE.md).

OpenAI, ChatGPT, Codex, Cerebras, Qwen, and other model/provider names identify services or recorded configurations. This is an independent project, not an official product or endorsement by those providers. Provider accounts and API usage are separate from this source distribution.
