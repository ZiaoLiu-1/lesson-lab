The starting point

From a study habit
to a small experiment.

I usually turn course material into HTML study guides and talk through them with ChatGPT Voice Chat. I wanted the page itself to take part in that conversation.

In Lesson Lab, a question and the current page go to the Cerebras API. It returns updated HTML, CSS, and SVG: a different example, a revised diagram, or another way to explain the idea. I can inspect the source, undo an edit, or save the page.

This is a local prototype, not an integration with ChatGPT Voice Chat. The site you are reading is its static showcase; it does not run inference.

Under the page.

Node.js · Vanilla JavaScript · HTML / CSS / SVG

01A complete page, not a chat bubble
A local Node.js server connects the browser to the API. Canvas sends the current static document and selection context, then displays the checked result in a scripts-blocked preview.
02Late replies stay in the past
Reader anchors, document revisions, and cancellation checks prevent stale responses from replacing the current page. Speech requires acknowledgement of the exact displayed version.
03Keep the last good version
Local file-backed state, bounded undo history, and save checks preserve accepted content when an edit fails. Generated application code is not executed.

Still an experiment. Valid markup is not proof of correct teaching. Explanations and diagrams need review; optional voice features need real-device checks. This is a single-reader local demo, not a multi-user service.

View the repository ↗

Start here

git clone https://github.com/ZiaoLiu-1/lesson-lab.git
cd lesson-lab
cp .env.example .env

Add your key to the local .env file, then run npm start. Open http://127.0.0.1:4320/.

The prepared sample can be browsed without a key. Live edits send your question and page source to the provider and may incur charges. Keep keys on the local server, never in the webpage.
