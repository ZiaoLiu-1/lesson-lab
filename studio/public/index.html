YOUR LOCAL WORKSPACE

A few things to know.

Study at your own pace

Start learning to hear the lesson and follow its highlighted passages. Interrupt with a question whenever you need to. Text & tools opens the written discussion and page navigation; manual lesson controls are available below the current step.

Changing page, selection, parameter, or model stops the current response. End learning releases the microphone. Undo restores the page before its last AI edit.

Motion diagnostics

No animated transition measured yet.

Keyboard: ⌘/Ctrl + Enter sends your draft. Escape stops the current activity. Alt + ← / → changes page when you are not typing.

Prepared Study uses calculated diagrams and saved AI notes. Live Canvas sends the complete current HTML to Cerebras for edits to layout, CSS, SVG and content. Use Save HTML or Undo to keep control of its generated source. The separate two-engine comparison measures HTML/SVG editing. Start it with npm run benchmark:api, then open the live comparison from Evidence.

Files stay under your control

Session import restores this same lesson and version. Lesson JSON imports a new validated lesson pack and archives the previous session. Packs must use the supported function model. PDF conversion is not included.

Voice & setup

Start learning enables continuous local microphone capture and local speech recognition, with Cerebras replies and local read-aloud. Speaking interrupts a reply. Say “continue” to resume the lesson or “stop listening” to end. End learning releases the microphone; it never starts again on its own. The separate Mic button in Text & tools keeps transcript review before sending and may use your browser’s online recognition service.

The microphone is off on load. Learning mode reads confirmed replies automatically and bypasses Codex. Use headphones for the first check; speaker echo cancellation and local speech output need device testing.

Only voices reported as local and English are listed; playback availability can vary.

For live answers, set CEREBRAS_API_KEY in the server environment, restart the local Studio server, then Reconnect. The key is never entered into this page.

AI explanations can be wrong. Numerical claims are checked against the graph's calculated values; that does not verify every sentence. This sample is a study aid, not a graded assessment.
